## 0. POR QUÉ EXISTE ESTE DOCUMENTO

La auditoría constata: **0 fotografías** de oficinas, equipo, obra, escritura, plano real o documento de XARU en todo el sitio, y **178 bloques marcados `REAL_MEDIA_REQUIRED`** que ninguna búsqueda de stock puede desbloquear. Este material no es "mejora visual": es la condición para que el sitio pueda afirmar lo que afirma.

**Regla rectora.** El stock cubre categorías y capacidades. Todo lo que este documento lista es **concreto** — y por tanto sólo puede producirlo XARU.

### Especificación técnica común a todo el rodaje

| Parámetro | Especificación |
|---|---|
| **Formato** | RAW + JPEG. Entrega en TIFF/JPEG de calidad máxima, sin recorte destructivo. |
| **Resolución mínima** | 6000 px de lado largo para fotografía de espacio y activo; 3000 px para retrato y detalle. |
| **Orientaciones** | Cada ítem se captura **en las dos orientaciones indicadas** (horizontal para desktop, vertical 4:5 para móvil). Nunca se recorta una horizontal para obtener la vertical: se dispara otra. |
| **Óptica** | 24-70 mm equivalente para espacios (evitar el gran angular deformante de folleto), 85 mm para retrato, 16-24 mm sólo para pasillos y salas estrechas con verticales rectificadas en postproducción. |
| **Luz** | Natural siempre que sea posible, con rebote. Flash sólo de relleno. Prohibida la luz de color y el contraluz dramático. |
| **Color** | Balance de blancos neutro medido con carta gris en cada espacio. Perfil final según Fase 12: saturación −20 %…0 %, contraste cinematográfico moderado, negros con detalle. |
| **Prohibido en rodaje** | Cielos reemplazados, HDR, staging de catálogo, personas posando a cámara con sonrisa comercial, atrezo alquilado, retoque de piel, marcas de terceros a la vista. |
| **Metadatos obligatorios** | Autor · fecha · ciudad · espacio · personas que aparecen · nº de cesión de imagen · uso autorizado (web, 4 idiomas, redes, duración). |
| **Cesiones** | Cesión de imagen firmada por cada persona reconocible. *Property/location release* para todo activo de terceros. Sin firma, la toma no se publica. |
| **Confidencialidad** | Ningún documento, pantalla, pizarra, etiqueta o pantalla de móvil puede tener texto legible. Verificar a 400 % antes de entregar. |

**Prioridades:** **P1** desbloquea bloques críticos hoy vacíos o falseados · **P2** completa la capa de credibilidad · **P3** enriquece.
