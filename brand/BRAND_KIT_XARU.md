# XARU HOME — Kit de marca v1
> Generado por vectorización del logo original (30-jul-2026). Todo editable: SVG con grupos `monogram`, `xaru`, `home`.

## Piezas (cada una en SVG + PNG 2048px transparente + PDF)
- `XARU_HOME_lockup_*` — logo completo (monograma + wordmark)
- `XARU_monogram_*` — solo el arco trenzado
- `XARU_wordmark_*` — solo XARU HOME

## Variantes de color y regla de uso (kit de legibilidad)
- `gold` — degradado oro (#C9A876 → #A98B5F → #8B6E45). Para fondos claros: arena, blanco, papel.
- `black` — negro carbón #1C1B19. Para fondos claros cuando se quiera sobriedad máxima.
- `white` — blanco total. OBLIGATORIA sobre fondos oscuros o de color (incluido el propio oro).

## Paleta base de marca
- Arena (fondo): #F5F1E8
- Oro claro: #C9A876 · Oro medio (plano): #A98B5F · Oro oscuro: #8B6E45
- Negro carbón: #1C1B19 · Blanco: #FFFFFF

## Tipografía de acompañamiento (web/documentos)
El wordmark es trazado (no fuente). Para textos: Playfair Display (títulos) + Poppins (cuerpo).

## Notas técnicas
- Origen: trazado potrace sobre ampliación 6× del original; curvas Bézier suaves auditadas a 4000px.
- El SVG del lockup conserva la proporción y respiración original del logo.
- Zona de protección sugerida: la altura de la palabra HOME alrededor de todo el logo.
